# Formula reference

Engineering cards display units beside each input and result. Use consistent SI values unless the input explicitly names another unit.

## Electrical engineering

- Ohm's law: `V = I × R`, `I = V / R`, `R = V / I`. Enter any two of voltage (V), current (A), and resistance (Ω) to calculate the third.
- Electrical power: `P = V × I` (watts).
- Series resistance: `Rtotal = R1 + R2 + R3 + …` (Ω).
- Parallel resistance: `1/Rtotal = 1/R1 + 1/R2 + …` (Ω).
- Voltage divider: `Vout = Vin × R2 / (R1 + R2)` (V).

## Mechanics and physics

- Force: `F = m × a` (N), mass in kg, acceleration in m/s².
- Kinetic energy: `KE = ½ × m × v²` (J), velocity in m/s.
- Potential energy: `PE = m × g × h` (J), height in m and gravity in m/s².
- Density: `ρ = m / V` (kg/m³).
- Momentum: `p = m × v` (kg·m/s).
- Work: `W = F × d` (J).
- Mechanical power: `P = W / t` (W).

## Error analysis

- Absolute error: `|measured − true|`.
- Relative error: `absolute error / |true|`.
- Percentage error: `relative error × 100%`.

The true value must be non-zero for relative and percentage error.

## Quadratic equation

For `ax² + bx + c = 0`, discriminant `D = b² − 4ac` and roots `x = (−b ± √D)/(2a)`. `D > 0` gives two real roots, `D = 0` gives one repeated real root, and `D < 0` gives a complex-conjugate pair. The coefficient `a` must be non-zero.
